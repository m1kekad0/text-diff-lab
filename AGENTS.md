# Working on text-diff-lab

- Read and apply the pinned shared rules in [vendor/ai-agent-rules/AGENTS.md](vendor/ai-agent-rules/AGENTS.md) alongside this file. Precedence is: platform constraints > user instructions > this file > pinned shared rules. The shared rules do not weaken this project's gates. See [provenance and update instructions](vendor/ai-agent-rules/PROVENANCE.md).

- The browser-local line comparison MVP and CI are implemented. Keep each change within the requested scope; add further features only when requested.
- Use a separate work branch. Preserve unrelated work and keep changes small enough to review.
- Before publishing, inspect all outgoing commits and tracked files, including author, committer, coauthor trailers, docs, PR text, logs, and images. Use only approved public identities. Exclude secrets, personal email, identifying local paths, and private material. Use relative paths and synthetic examples in public evidence.
- Write project-specific public documentation. Do not copy private rule sets, private links, or other projects' history and evidence. Check redistribution rights and license notices before adding third-party material.
- Keep text processing in browser memory. Do not add transmission, storage, analytics, services, or deployment outside the requested scope.
- Run relevant lint, tests, and build. Report what was actually checked and what is still missing. Obtain an independent review of a fixed commit; after changes, verify and review the updated commit.
- Push normally and open a Draft PR with evidence and limitations. Do not push directly to main, force push, merge, or change repository/account settings.
- An AI agent may mark a PR "Ready for review" only when all of these hold for the current HEAD: (1) an independent AI review is complete with no open findings, (2) CI has passed, and (3) only final Human confirmation remains. If no applicable CI exists for the change (e.g. no workflow is triggered), only condition (2) is waived: the agent may mark the PR Ready once independent AI review is complete with no open findings and only final Human confirmation remains. Otherwise keep it Draft. If a PR needs further changes after it has been marked Ready, first move it back to Draft with `gh pr ready <n> --undo`, then make the changes, re-review, and get CI passing (where CI applies) before marking it Ready again. Merge remains Human-only; Human decides when to merge.
